# GROWLY — 내 경험이 자라는 취준 대시보드

Flask로 만든 경험정리 분석 대시보드입니다. 내 이력(엑셀·문서 업로드 또는 직접 입력)과 강점 진단 결과를 분석해
추천 직무, 직무별 TOP 3 경험, 자소서 어필 포인트를 보여 줍니다.

## 1. 처음 실행하기 (VS Code)

1. VS Code에서 **파일 → 폴더 열기**로 이 폴더(`jobprep-dashboard`)를 엽니다.
2. 터미널(**보기 → 터미널**)에서 가상환경을 만들고 패키지를 설치합니다.

   **Windows (PowerShell)**
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements-dev.txt
   copy .env.example .env
   ```
   **macOS / Linux**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements-dev.txt
   cp .env.example .env
   ```
3. `.env`를 열어 `SECRET_KEY`에 임의의 긴 문자열을 넣습니다.
   (`python -c "import secrets; print(secrets.token_hex(32))"` 결과를 붙여넣기)
4. DB를 만들고 로그인용 데모 계정을 만듭니다(가상 데이터는 넣지 않아요).
   ```bash
   flask db upgrade
   flask seed-demo
   ```
5. 실행: VS Code로 폴더를 열면 **대시보드 실행 (자동 새로고침)** 작업이 서버를 자동으로 켭니다(처음 한 번 '자동 작업 허용'을 눌러 주세요).
   직접 켤 때는 터미널에서 `flask run --debug`.
   개발 모드에서는 파일을 저장하면 열린 브라우저 화면이 자동으로 새로고침돼요(VS Code 자동 저장 켜짐).
6. 브라우저에서 http://127.0.0.1:5000 접속 → `demo@tradeready.local` / `demo1234` 로 로그인
   (본인 계정은 회원가입으로 따로 만드세요.)

## 2. 화면 구성

| 화면 | 하는 일 |
| --- | --- |
| 경험 분석 (첫 화면) | ① 나에게 맞는 직무: 직무를 고르지 않아도 모든 이력을 분석해 추천 직무 3개(직접 고르기도 가능) → ② 그 직무 TOP 3 경험 카드(적합도·강점 링, 자소서 팁) → ③ 직무별 레이더·경험별 막대 차트 → ④ 종류별 모아보기(인턴·아르바이트·프로젝트 등 필터) → ⑤ 이력 추가·관리(경험/자격증/파일/내 데이터) |
| 강점 연결 | 강점 진단 결과지(PDF·DOCX·TXT 또는 붙여넣기)를 올리면 강점 이름·설명을 뽑아 그 강점이 드러난 내 경험과 연결, 강점×경험 연결 지도, (키가 있으면) AI 강점 스토리 |
| 공고 매칭 | 채용공고 링크(또는 붙여넣기)를 읽어 왼쪽에 공고 원문(글머리 기호 없이 원문 그대로, 노랑=내 경험과 겹치는 단어·초록=내 강점 단서), 오른쪽에 추천 경험과 '공고 문장 ↔ 내 경험 문장' 근거, 내 강점·자격증 연결, 보완 키워드. (키가 있으면) AI 매칭 리포트. 분석하면 먼저 "최근 조회 기록"에 남고(개별·전체 삭제 가능), 마음에 드는 공고만 ★ 저장. 저장한 공고는 산업(자동 분류·수정 가능)·직무별로 거르고 2~4개를 나란히 비교. 강조·추천은 직무 핵심어·자격증·어학·툴처럼 의미 있는 단어가 공고의 자격요건/우대사항과 실제로 겹칠 때만 하고('본인이·실제' 같은 일반 단어는 무시), 강점은 내 경험이 뒷받침할 때만 표시. **이미지로 된 공고**(모집부문·직무내용·자격요건·우대사항 표)는 링크 속 본문 이미지나 직접 올린 캡처를 AI(비전)로 읽어 모집부문별 카드로 보여 주고 매칭에 반영(OPENAI_API_KEY 필요, 공고 1건당 비전 호출 1회) |
| 자소서 보관함 | 제출한(또는 쓰는 중인) 자기소개서 문항·답변과 기업 정보(사업·인재상·메모), 진행 상태를 저장. 상태별 필터·검색, 답변에 쓴 내 경험 자동 표시, 2~3개 나란히 비교(같은 경험을 여러 곳에 쓴 경우 표시). 공고 매칭 화면에서 바로 만들 수 있고 저장본에도 포함 |
| 이력 PDF | 경험 분석 화면의 '내 이력 PDF로 저장' → 인쇄용 정리 페이지에서 브라우저의 'PDF로 저장' |

직무는 무역(해외영업·글로벌마케팅·무역사무·관세·포워딩·SCM 등)에 영업지원·인사(HR)·경영지원까지 5개 직군 16개예요.

**자격증·어학**: 경험과 따로 저장해요. `app/core/certificates.py`의 표로 직무별 관련도를 매기고(예: 국제무역사 → 무역사무 100·해외영업 85, TOEIC은 점수에 따라 조정), 관련도 높은 자격증 2개 × 15%(최대 25점)를 그 직무 적합도에 더해요. 엑셀의 '자격증' 행도 자동으로 자격증으로 들어가요.

**TOP 3에서 빼기**: TOP 3 카드의 '✕ TOP 3에서 빼기'를 누르면 그 직무에서만 제외되고 다음 순위가 올라와요. 아래 '뺀 경험'에서 되돌릴 수 있어요.

**저장·불러오기**: 06 → '저장·불러오기' 탭에서 지금의 경험·자격증·강점 결과지를 저장본으로 남기고 다시 불러올 수 있어요(불러오기·전체 지우기 전 상태는 자동 저장). '파일로 내려받기'한 .json 을 다른 컴퓨터나 배포한 사이트에서 올리면 그대로 옮겨져요. 강점 결과지도 여러 개 저장해 두고 강점 연결 화면에서 골라 불러올 수 있어요.

**경험 추가·업데이트 규칙** (`app/experiences/services.py`)
- 파일 없이 역할·내용·강점·키워드·느낀점을 입력할 수 있어요.
- 같은 이름의 경험이 이미 있거나 목록에서 기존 경험을 고르면 새로 만들지 않고 그 경험에 덧붙입니다(중복 문장·키워드는 제외).
- 엑셀을 다시 올려도 같은 이름의 경험은 업데이트되고, 분석은 화면을 열 때마다 최신 내용으로 다시 계산됩니다.

**자격증·어학**: 경험 추가 칸 옆 '자격증·어학 추가'에서 이름·점수·취득일을 넣어요. 같은 이름이면 업데이트되고, 직무 적합도 계산에도 반영돼요.

**자소서 어필 코멘트(AI)**: TOP 3 표 아래와 경험 목록의 '코멘트 보기'에 경험별로 어필 포인트·추천 문항·첫 문장 예시·보완할 점이 나와요.
- `.env`에 `OPENAI_API_KEY`(platform.openai.com/api-keys에서 발급, 유료)를 넣고 서버를 다시 켜면 'AI 코멘트 받기' 버튼이 생겨요. 모델은 `AI_MODEL`(기본 `gpt-5.4-mini`).
- 키가 없으면 규칙 기반 '기본 코멘트'만 보여요. 코멘트는 직무별로 저장되고, 경험을 고치면 '경험 내용이 바뀌었어요'로 표시돼요.
- 코멘트를 받을 때 그 경험의 내용이 OpenAI API로 전송됩니다.

**내 데이터 관리**: '04 이력 추가·관리 → 내 데이터 관리' 탭에서 어떤 파일이 언제 올라왔는지 보고, 파일별로 지우거나 전체를 지울 수 있어요. 앱은 PC의 파일을 스스로 읽지 않아요.

**엑셀 업로드**: 한 행이 경험 하나. `경험명/활동명`, `기관명`, `종류`, `기간`, `개월`, `나의 역할`, `key-word`, `강약점`,
`느낀점` 같은 머리글을 자동으로 찾고, 한 시트에 표가 여러 개 쌓여 있어도 표마다 머리글을 다시 읽습니다.

무역 직무 사전은 `app/core/trade_roles.py`에서 바꿀 수 있습니다. 분석 결과가 마음에 안 들면 이 파일의 키워드를 보강하는 것이 가장 빠릅니다.

## 3. 외부 연결 원칙

- **AI 코멘트**: `app/integrations/ai_client.py`에서만 OpenAI API를 부릅니다. 버튼을 눌렀을 때만 호출하고 결과는 DB에 저장해 다시 부르지 않아요.

- **공고 링크 분석**: 사용자가 넣은 링크 1건만 그 자리에서 읽습니다(사설 IP 차단). 로그인·앱 전용 공고는 본문 붙여넣기나 캡처 이미지 올리기를 쓰세요. 공고 이미지는 분석할 때만 받아 AI에 보내고 저장하지 않습니다(읽어 낸 글과 이미지 주소만 저장).

## 4. 자주 쓰는 명령

```bash
flask run --debug          # 개발 서버
pytest                     # 테스트 (데이터 분리 테스트 포함)
flask db migrate -m "설명"  # 모델을 바꾼 뒤 마이그레이션 파일 생성
flask db upgrade           # DB에 적용
```

## 5. 배포 (SQLite → PostgreSQL)

코드는 그대로 두고 환경변수만 바꿉니다.

1. GitHub에 올립니다(`.env`, `instance/`는 `.gitignore`로 제외됨).
2. Render 대시보드에서 **New → Blueprint**로 이 저장소를 연결하면 `render.yaml`대로 웹 서비스 + PostgreSQL이 만들어집니다.
3. `SECRET_KEY`는 자동 생성되고 `DATABASE_URL`은 자동 연결됩니다. `OPENAI_API_KEY`는 Render 대시보드의 Environment에 직접 넣으세요.
   배포 DB는 비어 있으니 회원가입으로 **내 계정**을 만들고 엑셀을 다시 올리세요. 그다음 `ALLOW_SIGNUP`을 `0`으로 바꾸면 다른 사람은 가입할 수 없어요
   (로그인이 없으면 주소를 아는 누구나 내 이력을 보고 내 OpenAI 크레딧을 쓸 수 있으니 로그인은 꼭 유지하세요).
4. 배포 시 `flask db upgrade`가 먼저 실행되어 테이블이 생깁니다.

무료 웹 서비스는 쉬는 동안 잠들 수 있지만 데이터는 PostgreSQL에 있어 사라지지 않습니다.
무료 DB 플랜의 보관 기간·용량 제한은 플랫폼 정책을 확인하세요. Docker로 다른 곳에 올리려면 `Dockerfile`을 쓰면 됩니다.

## 6. 폴더 구조

```text
jobprep-dashboard/
├── app/
│   ├── __init__.py          # create_app(): 설정·확장·블루프린트 조립
│   ├── config.py            # dev / test / prod 설정 (환경변수에서 읽음)
│   ├── extensions.py        # db, migrate, login_manager, csrf
│   ├── models.py            # 모든 모델 import (마이그레이션용)
│   ├── cli.py               # flask seed-demo
│   ├── core/                # 공통: 믹스인, 내 데이터만 조회(scoping), 무역직무 사전, 개발용 자동 새로고침
│   ├── auth/                # 회원가입·로그인
│   ├── applications/        # 자소서 보관함: 지원 기록·자소서·기업 정보, 비교
│   ├── strengths/           # 강점 결과지 파싱·경험 연결(services), 강점 연결 화면
│   ├── experiences/         # 파일 파싱(parser), 직무 분석(analyzer), 추가·업데이트·코멘트(services), 공고 매칭(posting)
│   ├── integrations/        # 외부 API: ai_client.py (OpenAI 자소서 코멘트)
│   ├── templates/           # 화면
│   └── static/              # css, js, vendor/chart.umd.js
├── migrations/              # DB 스키마 변경 이력
├── scripts/seed_demo.py     # 로그인용 데모 계정
├── samples/                 # 업로드 테스트용 샘플(.docx)과 엑셀 양식(.xlsx)
├── tests/                   # pytest
├── .vscode/                 # 실행 설정, 권장 확장
├── .github/workflows/ci.yml # push마다 테스트
├── render.yaml  Procfile  Dockerfile  wsgi.py
└── .env.example             # 필요한 환경변수 목록
```
